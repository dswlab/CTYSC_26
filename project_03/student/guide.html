여러분이 만드는 것은 정해진 이동 경로가 아니라 길을 선택하는 규칙입니다. 센서와 이동 엔진은 준비되어 있습니다. 조건문과 제공된 함수 블록을 조립해 보세요.

01. 파일을 열고, 수정할 곳 찾기

  1. 엔트리 오프라인 실행 프로그램에서 파일 → 불러오기로 downloads/student-maze-map1.ent를 엽니다.
  2. 오브젝트 목록에서 ① 학생 코딩 · 여기만 수정을 선택합니다.
  3. 판단하기 ★ 학생 수정 신호를 받았을 때 블록을 찾습니다.
  4. 그 아래에 조건문과 움직임 함수 블록을 연결합니다. 처음에는 전진하기만 들어 있습니다.
학생용 파일 받기동작 미리보기 열기 ↗

위 링크는 이 HTML과 실습 파일이 같은 폴더에 있을 때 동작합니다. 미리보기는 동작 설명용이며, 실제 블록 수정은 엔트리에서 합니다. 블록 예시의 색과 모양은 실제 엔트리 화면과 다를 수 있습니다.

학생은 판단만 담당합니다. 센서 측정 → 학생의 판단 → 실제 이동 → 다시 센서 측정은 엔진이 반복합니다. 학생 코드에 무한 반복이나 좌표 이동 블록을 따로 추가하지 않습니다.

02. 우리가 제공하는 행동 함수 5개

블록 꾸러미의 함수 분류에서 아래 블록을 끌어옵니다. 이름을 직접 입력하거나 함수를 새로 만들 필요가 없습니다.

제공 함수선택한 행동
전진하기현재 바라보는 방향으로 20만큼 이동합니다.
우회전하고 전진하기오른쪽으로 90도 회전한 뒤 20만큼 이동합니다.
좌회전하고 전진하기왼쪽으로 90도 회전한 뒤 20만큼 이동합니다.
뒤돌아 전진하기180도 회전한 뒤 20만큼 이동합니다.
정지하기이동을 멈추고 실행을 종료합니다.
한 번의 판단에서는 함수 하나만 선택하세요. 이 함수는 엔진에 행동을 알려 주는 블록입니다. 여러 함수를 나란히 넣어도 차례대로 이동하지 않고 마지막에 선택한 행동만 적용됩니다. 함수 정의는 수정하지 않습니다.

선택한 방향의 여유가 20 이하이면 엔진이 이동하지 않고 안전 정지합니다. 회전만 하는 별도 함수는 제공하지 않습니다.

03. 조건 판단에 쓰는 센서 변수

자료 → 변수에서 다음 변수의 값을 가져옵니다. 센서 값은 자동으로 바뀌므로 학생이 직접 값을 정하지 않습니다.

제공 변수무엇을 알려 주나요?
앞 여유현재 방향으로 충돌 없이 더 이동할 수 있는 거리
오른쪽 여유오른쪽으로 방향을 바꾸었을 때 이동할 수 있는 여유 거리
왼쪽 여유왼쪽으로 방향을 바꾸었을 때 이동할 수 있는 여유 거리
한 번 이동 거리한 번의 이동 거리. 시작하면 엔진이 20으로 설정합니다.

이동 가능한 조건

앞 여유 > 한 번 이동 거리

앞 여유가 35이면 전진 가능.
앞 여유가 20 또는 10이면 전진 불가.

비교에는 ‘이상(≥)’이 아니라 ‘보다 큼(>)’을 사용합니다. 숫자 20을 직접 넣어도 됩니다.

방향과 거리 읽기

  • 앞·오른쪽·왼쪽은 기체가 바라보는 방향 기준입니다.
  • 화면 오른쪽과 기체 오른쪽은 다를 수 있습니다.
  • 거리 단위는 화면 좌표이며 cm가 아닙니다.
  • 기체 크기를 반영한 안전 여유이며, 최대 표시는 120입니다.
조건 함수는 따로 제공하지 않습니다. ‘앞길이 열려 있음’이라는 전용 블록 대신, 기본 비교 블록 >의 양쪽에 센서 변수와 이동 거리를 넣어 조건을 만듭니다.

함수: 전진·회전 후 전진·정지 함수

기존 판단 신호를 받는 블록 아래에 조립합니다.

우리 팀의 규칙을 설계하세요. 오른손 규칙은 오른쪽 → 앞 → 왼쪽 → 뒤돌기 순서, 왼손 규칙은 왼쪽 → 앞 → 오른쪽 → 뒤돌기 순서로 확인합니다. 기본 조건문과 비교 블록, 제공된 행동 함수를 조립하세요. 완성 예시는 교사가 안내합니다.

05. 실행하고 다른 맵에서도 시험하기

  1. 맵 1에서 규칙을 만들고 실행합니다.
  2. 정지한 다음 속성 → 변수에서 맵 번호(1~3)를 2로 바꿉니다.
  3. 학생 코드는 그대로 두고 실행합니다. 맵 3에서도 같은 방법으로 시험합니다.
  4. 도착 여부·안전 정지 여부·이동 횟수를 기록합니다. 규칙을 바꾸면 이전 맵에서도 다시 시험합니다.
추가 제공 정보용도학생이 바꾸나요?
맵 번호(1~3)시험할 미로 선택정지 상태에서 1·2·3 중 선택
이동 횟수움직인 횟수 확인아니요. 자동 기록
상태실행 중·도착·정지 이유 확인아니요. 자동 표시
행동선택된 행동 확인직접 입력하지 않고 함수로 선택
판단하기 ★ 학생 수정 신호새 센서 값을 바탕으로 판단할 시점 알림기존 수신 블록 아래만 수정

센서·상태 외 변수는 화면에 보이지 않을 수 있습니다. 변수 목록에서 확인하세요. 이름이 ‘엔진_’으로 시작하는 변수, 내부 리스트 및 교사용 신호는 학생용이 아닙니다.

제공된 파일

  • downloads/student-maze-map1.ent: 맵 1에서 시작
  • downloads/student-maze-map2.ent: 맵 2에서 시작
  • downloads/student-maze-map3.ent: 맵 3에서 시작

각 파일에 세 맵이 모두 있습니다. 별도 학생용 파일은 ‘전진만’ 상태이므로, 같은 규칙을 시험할 때는 현재 작품의 맵 번호를 바꾸는 편이 편리합니다.

시험하고 기록하세요

도착 여부, 정지 이유, 이동 횟수를 기록하고 다른 맵에서도 같은 규칙을 시험하세요.

어떤 규칙도 임의의 모든 미로 탈출을 보장하지는 않습니다.

06. 자주 막히는 부분

‘전진하기’ 블록을 찾을 수 없어요.

기본 움직임 분류가 아니라 함수 분류를 확인하세요. 이 안내서와 함께 제공된 최신 .ent 파일을 다시 불러오세요. 예전 파일에는 제공 함수가 없습니다.

벽 앞에서 멈췄어요.

장애물 앞 안전 정지는 선택한 방향의 여유가 20 이하라는 뜻입니다. 조건에 사용한 센서와 행동 방향이 맞는지 확인하세요. ‘뒤돌아 전진’도 뒤쪽이 막혀 있으면 안전 정지합니다.

같은 곳을 계속 돌아요.

조건 우선순위, ‘아니면’ 중첩, 같은 위치·방향의 반복을 확인하세요. 600회 이동하면 반복 경로 점검 필요로 멈춥니다. 이는 탈출 불가능하다는 증명이 아닙니다.

아무 행동도 하지 않아요.

모든 조건 분기에 행동 함수가 있는지 확인하세요. 아무 함수도 선택하지 않으면 기본값인 정지로 처리됩니다. 판단 코드 안에 무한 반복을 넣지 않았는지도 확인하세요.

화면의 선과 점은 무엇인가요?

브라우저 미리보기에서 빨강은 앞, 보라는 오른쪽, 노랑은 왼쪽 센서입니다. 점선과 끝점은 가상 측정 범위이며, 옅은 주황 실선은 지나온 경로입니다. 엔트리 작품은 센서 끝점을 표시하며, 미리보기와 화면 구성이 다를 수 있습니다.

시작 전 점검
  • ① 학생 코딩 오브젝트를 선택했나요?
  • 기존 판단 신호 아래에 코드를 연결했나요?
  • 센서 값에 > 한 번 이동 거리를 비교했나요?
  • 한 번의 판단에서 함수 하나만 선택하나요?
  • 엔진·센서·맵과 함수 정의는 그대로 두었나요?
이 안내서는 제공된 센서 미로 실습 파일용입니다. 인터넷 없이 열 수 있으며 실제 드론 비행 설명서가 아닙니다. 엔트리 GUI에서의 파일 불러오기·함수 표시·실행은 수업 전 해당 버전에서 확인하세요.
